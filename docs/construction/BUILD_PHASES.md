# Staged construction sequence (a house build, not a one-shot rewrite)

| Stage | Contract / non-skippable result |
|---|---|
| 0. Layout + foundation | Domain identities; release/revision and permission gates; Node/React+TS PG monolith; safe private evidence; local tests and boot |
| 1. Inspector's completed room | Path B exact source; inspection launch, multi-unit forms, photos, partial, complete, PDF, linked concern and independent review; negative permission tests |
| 2. Supplier/engineering rooms | Full source/site supplier qualification and A/B/C sourcing; released baseline, FAI reject/resubmit, supplier acknowledgment and approval |
| 3. Quality/change rooms | All active Appendix A form shapes, NCR scoped disposition, SCAR/effectiveness/recurrence, concession, change implementation, controlled records/ENG/OPS PDFs |
| 4. Injector & management | Serialized test/repair chronology, validated import adapters, comparison report; dashboards, search, notifications, realistic metrics |
| 5. Final finishes | All 21 AT tests + adversarial cases; UI/detail layout matches PDI report examples; accessibility/phone/pagination; performance |
| 6. Inspections + occupancy permit | Staging Render PG+disk persist and restore; PDI signoff on technical standards and authority; backup/offsite copy; production go/no-go and controlled release |

Make every stage functional UI → API → persistent record → audit/evidence → controlled report → regression, not a route skeleton or static wireframe. Avoid reimplementing shared infrastructure in every stage. Get explicit signoff before paying for Render resources, using private data or releasing production.
